# 開發階段與工作清單

以下為一位工程開發者加一位兼任教學審查者的初步工作切分。6–8 週是排程假設，須依模型延遲、實拍資料與教學審查結果修正；品質門檻優先於日期。

## M0｜架構與可跑原型（目前）

- [x] 多科目、年級設定與可核對的讀題流程。
- [x] Mac webcam 預覽、手動框選、本機變化與停筆估計。
- [x] AI／Codex App Server 影像與結構化輸出介面。
- [x] 提示階梯、說明、複習題與本機語音介面。
- [x] 不含影像的手動學習紀錄匯出。
- [x] 雲端開關、OAuth 隔離、呼叫上限、錯誤處理、過期回應保護。
- [x] 合成資料自動測試、CI 與可執行示範。
- [ ] 有效 ChatGPT 帳號首次呼叫，確認圖像與 schema 實際相容性。

**退出條件**：全測試通過，使用者 Mac 可啟動；模型 smoke 通過後才能標記「大模型已連線」。

## M1｜實際作業與相機驗證（估 1–2 週）

| ID | 優先 | 工作 | 完成定義 |
|---|---|---|---|
| CAM-01 | P0 | 三種相機擺位／兩種光源拍攝測試 | 至少 60 張同意使用的照片，標記遮擋、模糊與可辨識度 |
| CAM-02 | P0 | 手寫數字、繁中、英文基準集 | 各科題意／作答比對，有錯例圖及教師真值 |
| CAM-03 | P1 | 校正畫面變化與停筆門檻 | 10 段各 10 分鐘，量測漏判與每 10 分鐘誤提醒 |
| AI-01 | P0 | AI 實測延遲與用量 | 分讀題／教學記錄 p50、p95、tokens、失敗率 |
| AI-02 | P0 | 登入／配額／拒答／逾時演練 | 不密集重試、不以舊回應覆蓋新題 |
| COST-01 | P0 | 每堂課方案用量限制 | 讀取帳戶配額與回復時間，達門檻停止 |
| UX-01 | P1 | 真實 Mac 中文語音與中斷 | 已安裝語音可播、暫停立即取消、無網路也可朗讀 |

**退出條件**：通過實機驗收表；不只用合成圖片與 fake webcam。

## M2｜科目教學品質（估 2 週）

| ID | 優先 | 工作 | 完成定義 |
|---|---|---|---|
| EDU-01 | P0 | 各科 rubric 與年齡難度 | 教師核准，可重放的 rubric 版本 |
| EDU-02 | P0 | 300 題最小評測集 | 各科 50 題，獨立標註與驗證，不以模型自評當真值 |
| EDU-03 | P0 | 錯判與答案洩漏測試 | 達 PRODUCT_PLAN 的門檻，各科分開報告 |
| EDU-04 | P1 | 複習題一致性與可解性 | 原題與複習題概念一致，答案／說明經核對 |
| EDU-05 | P1 | 開放題多解與歧義 | 不把合理替代答案判錯；資料不足先問清楚 |
| TOOL-01 | P1 | 單位／代數驗算工具 | 工具計算與模型回饋衝突時降級為不確定 |
| VIS-01 | P1 | 圖形、表格、地圖題 | 完整圖像上下文保留，缺圖時會要求重拍 |

**退出條件**：教師盲審教學品質達標，才能進入學生試用。

## M3｜小規模陪讀試用（估 1–2 週）

- [ ] 監護人同意與兒童易懂說明；明確告知哪裡有雲端運算。
- [ ] 先做成人扮演的試用，再安排少量學生，記錄誤提醒而非錄製人臉。
- [ ] 觀察主動求助、跳過提示、看答案與獨立做對變式題的比例。
- [ ] 檢查學生是否因過度提示而依賴；必要時拉長靜默或增加自我解釋。
- [ ] 與一般陪讀流程比較；不把前後測小樣本宣稱為因果證明。
- [ ] 決定是否加入經同意的本機長期概念記憶與家長摘要。

## M4｜可分發版本（估 1–2 週）

- [ ] macOS 應用包、簽章與更新；不用使用者開終端。
- [ ] OAuth 登入與登出體驗、設定精靈、用量警示、錯誤報告去識別。
- [ ] 可選課綱／教材檢索，引用來源與版本。
- [ ] 個人資料保留與刪除、匯出、使用者授權的跨日複習。
- [ ] 確認正式發布的政策、模型條款、應用授權及維護責任。

語音自由問答、即時語音打斷、多人教室、遠端家長監看另立需求；它們不應拖慢單人紙本陪讀的品質驗證。
